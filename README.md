# ✈️ CrewAI Travel Planner

A minimal AI-powered travel planner built with [CrewAI](https://github.com/crewAIInc/crewAI). Enter any city and a **Travel Planner agent** generates a detailed trip plan for it.

This project is a compact, beginner-friendly example of the core CrewAI building blocks: an **Agent**, a **Task**, and a **Crew**.

---

## 📌 Features

- Interactive CLI: just type a city name
- Single-agent CrewAI workflow with a clearly defined role, goal and backstory
- Verbose mode that shows the agent's reasoning as it works
- Easy to extend with tools, more agents, and output files

## 🧰 Tech Stack

| Component | Purpose |
|-----------|---------|
| Python 3.10+ | Language |
| [CrewAI](https://docs.crewai.com) | Agent orchestration framework |
| OpenAI API (default LLM) | Powers the agent |

## 🧠 How It Works

```
 User input (city)
        │
        ▼
 ┌───────────────────┐      ┌─────────────────────────┐
 │  Travel Planner   │ ───▶ │  Task: "Plan a trip to  │
 │      (Agent)      │      │        {city}"          │
 └───────────────────┘      └─────────────────────────┘
        │
        ▼
  Crew.kickoff()  ──▶  Detailed travel plan printed to the console
```

1. The user enters a city in the terminal.
2. A `Travel Planner` agent is created with its role, goal and backstory.
3. A `Task` describes the work and the expected output.
4. A `Crew` runs the task with `kickoff()` and prints the result.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/<your-username>/crewai-travel-planner.git
cd crewai-travel-planner
```

### 2. Create a virtual environment (recommended)

```bash
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
```

### 3. Install dependencies

```bash
pip install crewai
```

### 4. Set your API key

CrewAI uses OpenAI by default, so an API key is required.

```bash
export OPENAI_API_KEY="your-api-key"      # Windows (PowerShell): $env:OPENAI_API_KEY="your-api-key"
```

### 5. Run the project

```bash
python travel_planner.py
```

## 💻 Usage

```text
$ python travel_planner.py
Which city? Dubai
```

The agent then works through the task and prints a travel plan for the city you entered. With `verbose=True`, the agent's steps are shown in the terminal as it runs.

> Output varies between runs because it is generated by an LLM.

## 🔧 Code Overview

```python
planner = Agent(
    role="Travel Planner",
    goal="Plan a trip to a given city",
    backstory="You are a seasoned travel planner with extensive knowledge of various cities around the world.",
    verbose=True,
)

task = Task(
    description=f"Plan a trip to {city}",
    expected_output="A detailed travel plan for the specified city.",
    agent=planner,
)

crew = Crew(agents=[planner], tasks=[task])
print(crew.kickoff(inputs={"city": city}))
```

## 🛠️ Customization Ideas

- **Add live web search:** give the agent `SerperDevTool` from `crewai_tools` for up-to-date attractions, events and prices
- **Save the plan to a file:** add `output_file="trip_plan.md"` to the `Task`
- **Add more agents:** for example a Budget Analyst, a Local Food Expert, and an Itinerary Editor, run with `Process.sequential`
- **Add trip inputs:** trip length, budget, interests and travel dates
- **Enable memory:** pass `memory=True` to the `Crew`
- **Build a UI:** wrap it in Streamlit or Gradio
